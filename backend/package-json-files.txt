# Environment
NODE_ENV=development

============================================
INITIAL SETUP COMMANDS
============================================

# 1. Create project directory
mkdir real-estate-crm
cd real-estate-crm

# 2. Clone or create backend
mkdir backend
cd backend

# 3. Initialize backend
npm init -y
npm install express mongoose dotenv cors jsonwebtoken bcryptjs multer
npm install --save-dev nodemon

# 4. Create directory structure
mkdir models
mkdir routes

# 5. Create files (copy code from provided files)
# - server.js
# - models/User.js, Property.js, Client.js, Lead.js
# - routes/auth.js, properties.js, clients.js, leads.js, dashboard.js
# - .env
# - .gitignore

# 6. Go back and create frontend
cd ..
npx create-react-app frontend

# 7. Install frontend dependencies
cd frontend
npm install react-router-dom axios lucide-react tailwindcss

# 8. Copy all component files to src/components, src/pages, src/styles

============================================
RUNNING THE APPLICATION
============================================

Terminal 1 - Backend:
cd backend
npm run dev

Terminal 2 - Frontend:
cd frontend
npm start

The application will open at http://localhost:3000

============================================
COMMON SETUP ISSUES & SOLUTIONS
============================================

1. MongoDB Connection Error:
   - Check your internet connection
   - Verify connection string in .env
   - Make sure IP is whitelisted in MongoDB Atlas
   - Check database name is correct

2. CORS Error:
   - Backend is running on http://localhost:5000
   - Frontend is running on http://localhost:3000
   - They must be both running for requests to work

3. npm ERR! code ENOENT:
   - Make sure package.json exists in the directory
   - Delete node_modules and package-lock.json
   - Run npm install again

4. Port Already in Use:
   - Change PORT in backend/.env to 5001
   - Or kill the process using the port:
     - Mac/Linux: lsof -i :5000 | grep LISTEN | awk '{print $2}' | xargs kill
     - Windows: netstat -ano | findstr :5000

5. React App Won't Start:
   - Clear browser cache (Ctrl+Shift+Delete)
   - Delete node_modules in frontend folder
   - Run npm install again
   - Try npm start
